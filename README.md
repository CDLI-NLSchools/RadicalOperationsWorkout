# Radical Operations Workout

A practice app for **Math 2201, Unit 4 — Radicals** (Sections 2 and 3, Lesson 2).

Students work generated radical-operation problems one checked step at a time, in exact form, entering answers in structured fields (coefficient / radicand / variable parts — never free-text math). Every mode opens with a fully worked example, then a faded item with the last step left blank, then generated problems in a 10-item session; "Show this step" help is always available and is noted, not penalized. Indicators: **1.6** (operations with radicals) and **1.7** (rationalizing denominators). Variable modes assume variables are non-negative, per the course convention.

Modes:
- **Add / Subtract — numbers** — like radicals after simplifying each term
- **Add / Subtract — variables** — simplify-first composites with variable radicands
- **Multiply (including distribution)** — root × root, and a radical times a binomial (numbers and variables; distribution answered product by product)
- **Divide** — quotients of radicals, including variable quotients
- **Rationalize the denominator** — monomial denominators, plus a two-term-numerator stretch shape

Single-file HTML (`index.html`), no external resources — runs offline once loaded. Generator keys are verified by `harness.js` (2,000 draws per shape, independent key recompute, zero mismatches required).

Status: `draft` (work in progress; not yet in the CDLI applications index).
